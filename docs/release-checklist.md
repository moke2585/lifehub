### 真机回归发现并修复

- 编辑页保存后返回列表会保留重复页面栈，导致再次返回进入旧编辑页：改为回退到栈中已有页面。
- 底部“插件”标签在插件页内点击无响应：新增主页重置 token，点击标签回到主页根页面。
- 编辑页日期条未滚动到选中日期：`dateStrip` 打开时自动滚动到选中项。
- vivo 文件选择器隐藏 `.lifehub` 备份文件：导出扩展名改为 `.lifehub.zip`，MIME 改为 `application/zip`，已用同一文件验证导入。旧 `.lifehub` 文件可手动改名为 `.zip` 后导入。
- 任务清单日期滚轮初始选中项偏移：移除额外的程序化滚动，改为依赖滚轮初始居中状态，重新验证初始日期与滚动同步。
- 优先级第 5 档被横向裁切：选项文案改为 1–5，标签统一说明“5 最高”。
- 任务行标题被操作按钮挤压后换行：标题改为单行省略，并移除与右滑重复的“完成”文字按钮。
- 滚轮项高度改为随系统字体缩放，避免大字体下文字被裁切。
- 平板横屏页面单列浪费横向空间：新增 `wideLayout`，渲染器以第一个记录列表为界拆成 38%/62% 双栏。
- “保存并再记一笔”后方向 chip 未选中并提示“收支方向只能填写支出或收入”：初始化输入值时按 chips 选项过滤非法值。
- 键盘“搜索/完成”同时触发或只收起键盘：移除 `KeyboardActions.onDone`，只保留 `onSearch` 提交。
- 从账本进入统计页时，列表的搜索/方向参数被带入统计，导致摘要显示 0：筛选只作用于账本页，摘要始终按周期统计。
- 列表刷新后滑动删除可能触发已删除记录并提示“任务不存在”：记录行使用 `key(item.id)`，滑动动作改为 `rememberUpdatedState` 跟随当前 item。
- 200% 字体下插件顶栏副标题被裁切：字号大于 1.3 倍时只显示页面标题。
- 任务卡片动作增加到 4 个后触发“数据源条目动作数量超过上限 3”，整个任务列表加载失败：动作收敛为编辑/完成/置顶 3 个，卡片点击进入编辑。
- 从统计页进入预算再返回时滚动位置被重置：按路由缓存页面数据，返回时先渲染旧数据再刷新。
- 新增“筛选结果”指标后触发数据源指标上限（4），账本整页加载失败：上限调整为 5 并同步文档。
- 主动关闭搜索后仍保留上次关键词，最近搜索入口不可见：关闭时清空关键词，从结果返回时仍保留。
- 保存月度预算时结转开关与分类预算被静默清空：`PluginStorage.update` 的 id/payload 参数顺序写反，已修正。
- Gradle 守护进程 512m 堆在增量编译时 Metaspace 耗尽：调整为 2048m 堆 / 768m Metaspace。
- 主页小组件自定义后全部隐藏时入口消失：始终渲染“今日概览”头部与“自定义”按钮，并显示全部隐藏提示。
- 手动深色早期只改颜色角色，环图调色板仍取系统深色判断：新增应用级深色状态，图表、语义色与系统栏图标同步。
- 清除预算会连带删除结转与分类预算：改为只清除所选月份，保留其他设置。
- 柱状图柱子触控宽度仅 44dp，低于 48dp 最小目标：调整为 48dp，并补充搜索历史删除的 TalkBack 自定义动作。
- 旅迹全国地图点选城市后城市页提示“城市信息缺失”：区域动作只带 `regionId`，已补充区域级 `params`（`cityId`/`cityName`/省市信息），城市页与备注保存均可回退到正确城市。
- 旅迹在平板分栏中保存后，左侧全国地图仍显示旧数据：宿主新增 `dataRevision`，写操作返回 `Refresh`/`Navigate` 后所有挂载页面重新取数。
- 旅迹 v2 将旧备注迁移为“未评分”评价：新增 `TravelPlugin.migration` 并在 `SqlitePluginStorageFactory` 注册；真机旧库迁移成功，点亮记录与旧文字均保留。
- `dev-harness` 对 `dataSchemaVersion > 1` 的静态 warning 无法看到宿主迁移表，会误报已注册的迁移：移除该 warning，改由 `PluginDataSchemaManager` 运行时强制校验。
- 从“我的评论”打开地区页时继承了来源页面的省市参数，导致地区页显示杭州市而不是评论所属的会昌县：记录列表行、滑动与 `leadingAction` 改用精确参数触发（不再叠加当前页面初始参数），已在真机复验。

## 6. 已知限制

- 首版只支持随 APK 内置的第一方插件，不开放远程插件市场。
- 插件级 detached signature 尚未启用；APK v2+ 签名是当前信任锚。
- 安全模式以“仅加载 APK_SIGNED 内置包 + 自动停用故障插件”实现。
- `dev-harness` 是 CLI 校验与生命周期模拟工具，不渲染 Compose 页面。
- release 暂未开启 R8/资源压缩，避免未验证的序列化与反射裁剪风险。
- 备份导入要求数据 schema 版本一致，不尝试跨版本导入。
- 预算按月独立保存；旧版单一预算作为未单独设置月份的默认值。
- “最近使用”排序只统计从主页卡片、快捷新建或搜索结果打开插件的记录，通过底部标签切换不会更新顺序。
- 横屏首屏头部占用较高，插件卡片需要滚动才能完整查看。
- 旅迹内置边界数据中，东莞、中山、儋州、嘉峪关、天门、石河子、五家渠、北屯、铁门关、昆玉 10 个直筒子市/省直辖县级单位已用 OpenStreetMap 乡镇街道边界补齐（© OpenStreetMap contributors，ODbL）；济源、仙桃、潜江、神农架、海南 15 个省直辖县级单位以及双河、可克达拉、胡杨河等 25 个城市仍缺少免费的下级边界，暂以整市作为一个可点亮区域；台湾暂为单一区域。
- 三沙市位于全国地图的南海诸岛插图中，当前不参与省级下钻；其城市地图资产已内置，但入口暂不可达。
- 旧版备注迁移后只转为评论，不产生评分；v2 随评评分会按地区取平均并四舍五入为 1–5 星，作为该地区的唯一评分。
- 点亮、地区评分、评论三者独立；未点亮地区仍保留评分与评论，但其评分不参与城市/省份均分。
- 市/省均分只统计已点亮且至少有一条地区评分的下级区域；未评分或未点亮的区域不计入。
- 香港、澳门面积极小，全国地图上不显示省名标签，仍可直接点选。
- `dev-harness` 插件包大小上限已调整为 10MB，以容纳旅迹的离线省市县边界资产与地区搜索索引；页面与 manifest 仍受独立小限额约束。
- 内置“示例插件”仍随包发布，正式对外发布前可考虑移除或明确标记为示例。
- 当前 lint 有 4 个既有 warnings，发布前确认没有新增。

## 7. 回滚与热修复

- 版本发布后不得复用 versionCode；回滚必须使用更高的 versionCode 重新发布。
- 保留上一版 APK 与 SHA-256，便于用户侧手动回退（回退前必须评估数据版本兼容性）。
- 首版不提供远程热修复；紧急修复走完整构建、测试、签名、发布流程。
- 数据 schema 降级不受支持；迁移失败时保留旧数据并隔离插件，不自动删除。
- 备份格式变更必须提升 `formatVersion` 并提供导入兼容策略。

## 9. 发布步骤

1. 冻结版本号并更新本检查表。
2. 运行自动门禁与插件校验。
3. 配置签名环境变量，运行 `checkReleasePrerequisites` 与 `assembleRelease`。
4. `apksigner verify`，记录证书指纹与 SHA-256。
5. 在真机矩阵上执行回归，记录设备型号、Android 版本和结果。
6. 归档 APK、SHA-256、构建信息、签名证书指纹和已知问题。
7. 通过项目仓库的问题反馈渠道提供用户支持。
