# 决策记录（ADR）

本目录落实 `plan.md` 中 P0 的决策要求。规则如下：

- 一个决策一个文件，编号不复用；已接受的决策不直接改写，变更需新增 ADR 并在索引中标注“被替代”。
- 每条记录包含状态、日期、责任人、结论、理由、后果与变更方式。
- 责任人当前为项目维护者，团队组建后更新为具体姓名；涉及商店提审的合规结论必须由发行负责人复核后签字。
