# 首版范围冻结清单

- 版本：v1（2026-11-11）
- 责任人：项目维护者
- 依据：`plan.md`、ADR-0001 至 ADR-0005

## 纳入首版

- 宿主：Compose 壳、主题、错误页、插件列表、启用/禁用、插件页面路由。
- 插件契约：版本化 manifest、声明式页面 schema、action id、兼容性校验、结构化错误。
- 渲染：宿主标准组件（页面、标题、文本、按钮、列表、输入、金额/日期、确认框、加载/空态）、无障碍与大字体。
- 数据：按 `pluginId` 隔离的存储、schema 迁移、口令加密备份导出/导入、卸载保留与显式删除。
- 第一方插件：记账（增删改查、日期筛选）、备忘录（增删改查、搜索、置顶）。
- 稳定性：连续崩溃禁用、安全模式、按需初始化、日志脱敏。
- 发布：arm64 debug/release 构建、签名从环境注入、发布检查表。

## 明确不做

- 公开或私有插件市场、远程插件包下载、插件自更新、dex/APK 动态加载。
- QuickJS 或任何脚本 runtime（触发条件见 ADR-0001）。
- 网络、通知、相机、定位、任意文件访问、插件间数据总线。
- 云账号、自动云同步、支付、评分、审核后台。

## 完成判定

在 `lifehub/` 目录执行以下命令全部通过，且满足 `plan.md` 第 4 节 Definition of Done：

```powershell
.\gradlew.bat testDebugUnitTest :plugin-api:test lintDebug assembleDebug
```

## 后续版本扩展（不改变首版范围）

- 2026-11-23：批准插件市场与 ZIP/APK 安装形态，详见 [ADR-0006](0006-external-plugin-packaging.md)、[ADR-0007](0007-third-party-distribution.md) 与 [插件市场实施计划](../plugin-market-plan.md)。
- 首版仍不包含插件市场、远程插件、第三方代码分发；上述能力只在后续版本按新 ADR 执行。
- 后续版本必须保持插件 ID、集合名与备份 v1 兼容约束。

## 变更方式

任何新增范围必须先更新本清单并说明对信任模型、商店合规和数据语义的影响；不在本清单内的能力不得以“顺手实现”的方式进入首版。
